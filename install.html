📱 Cara Install di Android
1
Buka link ini di Chrome
2
Ketuk menu ⋮ (titik tiga) di pojok kanan atas
3
Pilih "Tambahkan ke layar utama"
4
Ketuk "Tambahkan" — selesai! Icon SGC muncul di homescreen
🍎 Cara Install di iPhone
1
Buka link ini di Safari (bukan Chrome)
2
Ketuk tombol Share di bagian bawah layar
3
Gulir ke bawah, pilih "Add to Home Screen"
4
Ketuk "Add" di pojok kanan atas — selesai!
✅ Aplikasi berhasil diinstall! Cari icon SGC Blok B di homescreen HP Anda.
